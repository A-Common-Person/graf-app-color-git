## Descripción
Graf App Color Git es una aplicación que permite visualizar y manipular gráficos con una paleta de colores personalizada. Diseñada para facilitar la representación visual de datos con estilos dinámicos.

## Características
- Soporte para múltiples esquemas de color.
- Interfaz intuitiva para modificar gráficos.
- Exportación de gráficos en formatos estándar.
